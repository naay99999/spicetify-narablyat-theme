Background Layer

Glass effect ต้องมีอะไรให้ "โปร่งผ่าน" — background ควรเป็นแบบไหน?

A — Solid White (ปัจจุบัน)
Glass แทบไม่เห็น เพราะ background = white เหมือนกัน
B — Subtle Gradient
Purple-blue-green gradient อ่อนๆ — glass จะมองเห็น translucency ได้ชัด
C — Ambient Color Blobs
Soft glow spots (เหมือน Apple Music) — glass จะดูมี depth และมีชีวิตมากที่สุด

B และ C ทั้งคู่ใช้ CSS ล้วน ไม่ต้องมีรูปภาพ performance ดีเท่ากัน
